## Objetivo da Sprint

A Sprint 3 teve como objetivo desenvolver uma Landing Page funcional para apresentar a solução do projeto Eletric Minds. A página foi estruturada utilizando HTML semântico, CSS Grid e técnicas de responsividade, garantindo uma boa adaptação para Desktop, Tablet e Mobile.

A Landing Page apresenta as seguintes seções:

- A Solução
- Público-Alvo
- Galeria
- Nossa Equipe
- Contato

Além da estrutura visual, o projeto conta com recursos de navegação, elementos gráficos, ícones, tipografia personalizada e adaptação para diferentes tamanhos de tela.
